RESET PASSWORD UPDATE
=====================

Added a password recovery block to the login window.

How it works:
1. Open "Forgot password? Reset it here".
2. Enter the unique User ID (for example P-1001).
3. Enter the registered username or email for that same account.
4. Enter and confirm a new password (minimum 8 characters).
5. The app verifies the User ID + account identifier and securely stores a new
   PBKDF2 password hash and salt in the Users worksheet.

Files updated:
- app_patient_diagnostics_fixed.py (main launcher target)
- app_diagnostics.py (kept in sync)

Security note:
The User ID remains the recovery key, but the app also checks the existing
username/email because User IDs are sequential and should not be treated as a
secret by themselves.
