IHS SERVICE ACCOUNT FALLBACK FIX

Problem
-------
The main Streamlit app stopped at startup when IHS/service_account.json was
missing, even though this project also contains a service-account key under
IHS/clinical_chatbot/service_account.json.

Fix applied
-----------
- app_patient_diagnostics_fixed.py now searches, in order:
  1. GOOGLE_SERVICE_ACCOUNT_FILE environment variable (when set)
  2. IHS/service_account.json
  3. IHS/clinical_chatbot/service_account.json
- app_diagnostics.py uses the same fallback.
- Error text now shows both supported locations if neither key exists.
- Python syntax was checked after the change.

This means the app can start with the chatbot-local credential copy when the
root copy is absent after extraction.

Security
--------
service_account.json is a private Google credential. Keep it private and do not
publish the project ZIP or commit the key to a public repository.
